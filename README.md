# mP3-Visualizer (Pulse Deck)

端末内の音楽をブラウザで再生し、音に合わせて描画するビジュアライザーです。スマートフォンやiPhoneのSafariでの操作も想定した、静的ファイルだけのアプリです。

## 使い方

1. `index.html` をブラウザで開くか、静的なローカルサーバー・GitHub Pagesで表示します。
2. **MP3を選ぶ**で最初の曲を選びます。**曲を追加**から1曲ずつ、合計3曲まで登録できます。
3. VISUAL、COLOR PATCH、SENSITIVITYを選び、**再生**を押します。一時停止・再開・停止もできます。
4. 使い終わったら**安全に終了**を押します。音と描画が止まり、終了メッセージが表示されます。

ファイル選択欄はMP3、WAV、OGG、MP4オーディオ（M4Aなど）を受け付けます。実際に再生できる形式・コーデックはブラウザの対応状況によります。

## 再生とプレイリスト

- 登録できる曲は最大3曲。曲名の一覧と、現在曲の番号・名前を表示します。各曲は一覧から削除できます。
- 複数曲は登録順に自動再生します。
- **REPEAT OFF**: 最後の曲で終了します。
- **REPEAT 1**: 現在の1曲を繰り返します。
- **REPEAT ALL**: 最後の曲の後、先頭に戻って繰り返します。
- STOPを押すと、リピート設定に関係なく再生が止まります。

## ビジュアルと色

VISUALは **RING / WAVE / BAR / ORBIT / AURORA / SPARK / MIST** の7種類です。

MISTはWebGL / GLSLで霧・煙のような流体表現をリアルタイム生成します。無音時にも霧は自然に動き、音楽に応じて形や流れが変化します。感度を上げると反応が強まり、強い音では霧の内部が柔らかく発光します。

COLOR PATCHはネオンブルー、アンバー、ラベンダー、桜ピンク、エメラルドグリーンの5種類。どのビジュアルでも切り替えられます。SENSITIVITYで音への反応を調整でき、中央のSIGNAL LEVELで信号の状態を確認できます。

## 端末内での処理

選択した音楽ファイルはブラウザ内でオブジェクトURLとして読み込み、Web Audio APIで解析します。現在のアプリコードには、音楽ファイルを外部サーバーへ送信・アップロードする処理はありません。

描画は最大45fpsに制御しています。再生停止時は音声解析用のAudioContextを休止し、RINGなどのCanvas 2Dモードでは連続描画を止めます。MISTは無音時も霧が動くため、選択中は描画を続けます。ページを離れたときは再生・描画を一時停止し、復帰時に音楽を勝手に再開しない構成です。

## ファイル構成

- `index.html`: 画面構造とファイル選択欄
- `style.css`: COLOR PATCHを含む画面デザインとスマートフォン向け配置
- `app.js`: 再生、プレイリスト、音声解析、6種類のCanvas 2D描画
- `mist.js`: MISTのWebGL / GLSL描画とカラーパレット
- `manifest.webmanifest`, `assets/icons/`: ホーム画面追加用の設定とアイコン

## GitHub Pagesへの公開

上記のファイルとフォルダをリポジトリのルートに配置し、GitHubの **Settings > Pages** で `Deploy from a branch`、`main` ブランチの `/(root)` を選びます。
